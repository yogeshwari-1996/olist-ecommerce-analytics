# Olist E-Commerce Analytics

End-to-end e-commerce analytics project using PostgreSQL and Python.

## Project Goal
Analyse Olist marketplace data to identify revenue trends, customer behavior, delivery performance, customer satisfaction, and late-delivery risk.

## Tools Used
- PostgreSQL / pgAdmin
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Git and GitHub

## Analysis Performed
- Data cleaning and validation
- Revenue and order trend analysis
- Customer and state-level performance
- Delivery-time analysis
- Review-score analysis
- RFM customer segmentation
- Late-delivery prediction using Logistic Regression
